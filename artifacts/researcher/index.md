# T3.2 — Official Parakeet Unified EN 0.6B integration contract

**Evidence cut:** Hugging Face API/repository queried 2026-08-08. This is upstream NVIDIA/Hugging Face evidence only; no weight was downloaded and no product code was inspected or changed.

## Decision this research informs
Whether T3.2 can implement a reproducible, **truthfully described buffered** Parakeet Unified challenger, and the exact upstream identifiers/configuration it must record.

## Findings (each: claim — evidence/source — confidence)

- **Use canonical model ID `nvidia/parakeet-unified-en-0.6b`; pin immutable revision `fe53cd885760c96b6a5f51a0bfd362cb4584a98b`.** The official HF model API reports both `id` and current `sha`; do not use the moving `main` ref for the benchmark. Source: [HF API](https://huggingface.co/api/models/nvidia/parakeet-unified-en-0.6b). **High.**
- **The pinned repository’s payload is `parakeet-unified-en-0.6b.nemo`, 2,474,055,680 bytes, with LFS SHA-256 `ec23ed9150c8fde49072c3e2d61678ab903dbcef389d658db833420cbc1da35b`.** The same tree reports README Git blob `bf94ccdb8513e6be7d7a316d3d1254f12503cab7`; full official tree/API: [tree at pin](https://huggingface.co/api/models/nvidia/parakeet-unified-en-0.6b/tree/fe53cd885760c96b6a5f51a0bfd362cb4584a98b?recursive=true&expand=true). The other LFS file is `figures/wer_comparison.png`, 402,185 bytes, SHA-256 `ef5fd7fd7b582cc56b02fdee2e9fbcde89c5a769cf3e68276a9dbb14251c5651`. **High.**
- **License is NVIDIA Open Model License Agreement**, URL [NVIDIA Open Model License](https://www.nvidia.com/en-us/agreements/enterprise-software/nvidia-open-model-license/). Model metadata names it `nvidia-open-model-license`; card says commercial/non-commercial use is ready. Source: [pinned official card](https://huggingface.co/nvidia/parakeet-unified-en-0.6b/blob/fe53cd885760c96b6a5f51a0bfd362cb4584a98b/README.md). **High.**
- **It is English (`en-US` training speech), Unified-FastConformer-RNNT, 24 encoder layers / 600M parameters; output is English text with punctuation/capitalization.** Source: [pinned card](https://huggingface.co/nvidia/parakeet-unified-en-0.6b/blob/fe53cd885760c96b6a5f51a0bfd362cb4584a98b/README.md#model-architecture). **High.**
- **This is buffered, not cache-aware streaming.** NVIDIA explicitly says the current inference pipeline “supports only buffered streaming (left context is recomputed for each chunk),” which can be longer than cache-aware streaming. It supplies the stateful chunked RNN-T script, not an interactive cache-aware public API. Source: [pinned card—streaming](https://huggingface.co/nvidia/parakeet-unified-en-0.6b/blob/fe53cd885760c96b6a5f51a0bfd362cb4584a98b/README.md#streaming-inference); [official script](https://github.com/NVIDIA-NeMo/NeMo/blob/main/examples/asr/asr_chunked_inference/rnnt/speech_to_text_streaming_infer_rnnt.py). **High.**
- **Supported/recommended contexts:** retain **5.6 s left** (training default); official `(left, chunk, right) seconds` presets are `(5.6,1.04,1.04)` = 2.08 s latency, `(5.6,.56,.56)` = 1.12 s, `(5.6,.16,.40)` = .56 s, `(5.6,.08,.24)` = .32 s, `(5.6,.08,.16)` = .24 s, and `(5.6,.08,.08)` = **.16 s**. NVIDIA defines theoretical latency as `chunk + right`; advertised granularity is 80 ms steps from 2.08 s to .16 s. Source: [pinned card—configuration](https://huggingface.co/nvidia/parakeet-unified-en-0.6b/blob/fe53cd885760c96b6a5f51a0bfd362cb4584a98b/README.md#setting-up-streaming-configuration). **High.**
- **Runtime contract:** the pinned card names **NeMo 2.7.3** and Linux/NVIDIA GPUs. The package family is `nemo_toolkit['asr']`; NVIDIA’s install guide also requires `libsndfile1`, `ffmpeg`, `Cython`, and `packaging`, and recommends `nvcr.io/nvidia/nemo:25.11` for its current docs. For faithful model execution, pin the card’s `nemo_toolkit==2.7.3` plus ASR extra (rather than silently substituting the newer docs container), then record PyTorch/CUDA resolved by that environment. Sources: [pinned card—software integration](https://huggingface.co/nvidia/parakeet-unified-en-0.6b/blob/fe53cd885760c96b6a5f51a0bfd362cb4584a98b/README.md#software-integration), [NVIDIA installation guide](https://docs.nvidia.com/nemo-framework/user-guide/25.11/installation.html). **Medium-high** (the exact `==2.7.3` pip resolver combination has not been installed in this task).
- **The official public API for ordinary loading is** `nemo.collections.asr.ASRModel.from_pretrained(model_name="nvidia/parakeet-unified-en-0.6b")`; it is appropriate for offline `transcribe`, but the model card’s truthful streaming API is the supplied `speech_to_text_streaming_infer_rnnt.py` with `model_path`, `left_context_secs`, `chunk_secs`, `right_context_secs`, and `att_context_size_as_chunk=true`. It performs full-buffer encoder calls and preserves decoder state across chunks; its source computes latency as chunk+right and removes left/right encoder context before chunk decode. Sources: [pinned card](https://huggingface.co/nvidia/parakeet-unified-en-0.6b/blob/fe53cd885760c96b6a5f51a0bfd362cb4584a98b/README.md#streaming-inference), [official script](https://github.com/NVIDIA-NeMo/NeMo/blob/main/examples/asr/asr_chunked_inference/rnnt/speech_to_text_streaming_infer_rnnt.py). **High.**
- **Precision is a runtime choice, not a pinned-model precision contract.** The official chunked-script configuration accepts `float32`, `bfloat16`, or `float16`; when unset it chooses bfloat16 if available, otherwise float32. Its official buffered pipeline config defaults `compute_dtype: bfloat16` for Ampere+ and says float16 for older GPUs. Thus RTX 4090 test configuration should explicitly record/force bf16 (or deliberately test fp16); do not claim the `.nemo` itself is an FP16/BF16 artifact. Sources: [official script](https://github.com/NVIDIA-NeMo/NeMo/blob/main/examples/asr/asr_chunked_inference/rnnt/speech_to_text_streaming_infer_rnnt.py), [official buffered config](https://github.com/NVIDIA-NeMo/NeMo/blob/main/examples/asr/conf/asr_streaming_inference/buffered_rnnt.yaml). **High for runtime options; high that on-disk weight dtype is not published.**
- **Input contract is mono 1-D WAV; model-card output is English.** A model-specific sample rate is **not published** in the card or repository tree. The upstream generic buffered pipeline YAML sets `streaming.sample_rate: 16000`, and the chunked script derives its rate from `model_cfg.preprocessor['sample_rate']`; that supports a 16 kHz *pipeline configuration* but does not attest it as the pinned `.nemo`’s model metadata without opening/downloading it. Sources: [pinned card—input](https://huggingface.co/nvidia/parakeet-unified-en-0.6b/blob/fe53cd885760c96b6a5f51a0bfd362cb4584a98b/README.md#input), [official script](https://github.com/NVIDIA-NeMo/NeMo/blob/main/examples/asr/asr_chunked_inference/rnnt/speech_to_text_streaming_infer_rnnt.py), [official YAML](https://github.com/NVIDIA-NeMo/NeMo/blob/main/examples/asr/conf/asr_streaming_inference/buffered_rnnt.yaml). **High for the uncertainty.**

## Prior art & competitive landscape

## Current-system reality (what actually exists today)
- T3.2 is recorded in `.sift/issues.jsonl` as in progress; this research performed no implementation inspection or edits.
- The official card is internally version-sensitive: an earlier pinned card revision names NeMo 25.11, while the **current pinned `fe53…` card names NeMo 2.7.3**. T3.2 must preserve the latter as the model contract and not copy old research notes.

## Constraints discovered (technical, legal, operational)
- **Blocker if misrepresented:** calling this “native/cache-aware streaming” is contradicted by NVIDIA; it recomputes left context each chunk.
- **Reproducibility:** `from_pretrained(model_name=...)` shown by NVIDIA has no revision argument in the documented call. Materialize/verify the exact `.nemo` by HF revision and LFS SHA-256 before passing its local `model_path` to the official chunked script; otherwise benchmark provenance is mutable.
- **License:** retain the linked NVIDIA Open Model License Agreement with distribution/use review; this is not Apache/MIT.
- **Operational:** raw microphone PCM needs conversion/resampling to model preprocessor rate. The official public evidence does not pin that model rate; a benchmark must log the actual loaded `model_cfg.preprocessor.sample_rate` before claiming it.

## Implications for scope
- Implement only a buffered/recomputed-context adapter, expose/persist its left/chunk/right values, and calculate/display theoretical latency as `chunk + right` plus observed inference time.
- Use the 5.6/.56/.56 preset for the direct 1.12 s card-backed matched configuration, or 5.6/.08/.08 only if explicitly testing NVIDIA’s 160 ms minimum-latency configuration.
- Record: model ID, `fe53…` revision, `.nemo` LFS SHA-256, NeMo environment and explicit compute dtype, audio resampling rate observed from the loaded config, and contexts. Do not state 16 kHz as established model metadata until that non-weight configuration is inspected from the pinned artifact.

## Still unknown (ranked, with how to resolve each)
1. **High — exact pinned `.nemo` preprocessor sample rate and serialized parameter dtype.** Neither official card nor HF API publishes them. Resolve in the implementation environment by inspecting the verified local artifact’s *configuration only* and logging `model_cfg.preprocessor.sample_rate` / tensor dtype; or request NVIDIA publish a standalone config. Safe fallback: resample to 16 kHz only as an explicitly labeled pipeline assumption, not an upstream fact.
2. **Medium — exact pip lock for `nemo_toolkit[asr]==2.7.3` with the project’s CUDA 13/PyTorch stack.** Official card supplies NeMo version, but not a complete constraints lock. Resolve with a throwaway environment install and capture `pip freeze`; do not use benchmark results until it imports the pinned model.
3. **Medium — production-friendly incremental API.** NVIDIA documents a batch/manifest chunked script/pipeline, not a stable microphone-session API. Resolve by adapting the official buffering algorithm behind the project seam and validating emitted partial/final semantics; label it buffered rather than cache-aware.
